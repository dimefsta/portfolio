# Just_Di.E — Portfolio

> Personal portfolio of **Dimitris Efstathiou** — Software Developer & Entrepreneur based in Athens, Greece.

🔗 **Live:** [just-die.com](https://www.just-die.com)

---

## About

A bento-grid style portfolio built entirely from scratch — no frameworks, no templates. Pure HTML, CSS and vanilla JavaScript.

Designed with a dark, minimal aesthetic and full mobile support (responsive bento → single-column tap-to-expand on mobile).

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 (semantic) |
| Styling | CSS3 (custom properties, grid, clamp) |
| Logic | Vanilla JavaScript (ES6) |
| Fonts | Google Fonts — Montserrat |
| Hosting | Custom domain (`just-die.com`) |

---

## Features

- ⚡ Bento grid layout — 4-column desktop, responsive tablet, single-column mobile
- 🕐 Live Athens timezone clock
- 🎓 15 certifications with modal image viewer
- 🌍 Language proficiency display
- 📱 Mobile tap-to-expand sections
- 🔍 SEO-optimised — meta tags, Open Graph, Twitter Card, JSON-LD schema, sitemap
- ♿ Accessible — skip link, ARIA labels, semantic HTML, keyboard navigation
- 🚀 Performance — preloaded LCP image, deferred JS, lazy loading
